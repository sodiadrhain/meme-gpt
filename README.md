# MEME GPT
A simple web3 tool for trading activities.

### Setup

### Prerequisites

- Python 3.8 or higher
- PIP

### Running App locally
Clone the [repository](https://github.com/sodiadrhain/meme-gpt.git) and proceed with the instructions below.

Install all requirements and dependancies

```
pip3 install -r requirements.txt
```

Then run

```
python3 main.py
```

### Running in a venv

```
python3 -m venv venv
```
```
source venv/bin/activate
```
```
pip3 install -r requirements.txt
```

Then run

```
python3 main.py
```

Note: if you have `python3` installed use `python3` and `pip3` instead of `python` and `pip`
